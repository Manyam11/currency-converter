# 💱 CurrencyPro

A modern and responsive Currency Converter built using React and Vite.

## 📸 Preview

>## 🌐 Live Demo

https://currency-converter-flame-phi.vercel.app

---

## ✨ Features

- 🌍 180+ Currencies
- 🔍 Searchable Currency Dropdown
- 🚩 Country Flags
- 🌙 Dark / Light Mode
- ⭐ Favorite Currencies
- 📋 Copy Converted Result
- 📜 Conversion History
- 🔄 Swap Currencies
- 🔔 Toast Notifications
- 📱 Fully Responsive Design
- ⚡ Real-Time Exchange Rates

---

## 🛠️ Tech Stack

- React.js
- Vite
- CSS3
- React Select
- React Circle Flags
- React Toastify
- Exchange Rate API

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Manyam11/currency-converter.git
```

Go to the project directory:

```bash
cd currency-converter
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
